Sending

How automatic sending works
Draw-Trac is a standalone page, so it cannot send mail on its own. To send automatically, create a small flow that receives each email and sends it (for example Power Automate: When an HTTP request is received then Send an email (V2); or Zapier, Make, or a Google Apps Script web app) and paste its URL above. Every email is POSTed as JSON (sent as text/plain so browsers allow it) with the fields to, cc, subject, html, text, program, role. Browsers cannot read the flow's reply, so "Sent to mail service" means the request reached the webhook. Without a webhook, each email opens ready-to-send in your mail app.
